プライバシーポリシー

更新日：2026年9月28日

本ポリシーは、Watch Recorderの時計用・Androidスマートフォン用アプリおよび本紹介サイトでの情報の取り扱いを説明します。

録音は、利用者自身のためのものです。Watch Recorderは、録音やGoogleユーザーデータを開発者へ送信しません。開発者がこれらを収集・保管・閲覧したり、独自の目的で利用したりする仕組みはありません。

1. 利用者のためにアプリが処理する情報

アプリは、利用者が録音した音声、録音日時・時間、分割ファイルの識別情報・整合性確認用ハッシュ値、転送状態、Google Drive上の保存先・ファイルID、連携・送信間隔の設定を扱います。これらは、利用者自身が音声を録音・再生・保存し、録音一覧を確認するために処理します。転送の再試行や保存内容の確認も、利用者の音声を正しく保存するための処理です。開発者によるデータ収集や分析のためには使用しません。

2. Googleへのアクセス

Googleの認可画面で許可を得たうえで、Google Drive APIの「drive.file」権限を使用します。アプリが作成したファイルや、利用者がアプリにアクセスを許可したファイルの範囲で操作する権限です。現在の実装は専用フォルダと録音ファイルの作成・保存・確認に使用し、Drive全体の読み取り権限は要求しません。

Googleのパスワードはアプリで取得しません。Googleの認可機能から受け取るアクセストークンはAPI通信のために使用し、アプリ独自のファイルや設定に永続保存しません。

3. 保存と転送

録音は時計内に保存し、Google Play servicesのWear OS Data Layerを介してスマートフォンへ転送します。スマートフォンはHTTPS通信で利用者自身のGoogle Driveへアップロードします。10秒以内に停止した録音は破棄し、スマートフォンやDriveへ送信しません。

開発者が運営する音声保管サーバーへ録音を送る機能はありません。Googleのサービスによるデータ処理には、Googleの利用規約・プライバシーポリシーも適用されます。

4. 保持期間と削除

時計内の録音は利用者が削除するまで保持します。未送信の音声は転送のために保持し、保存確認前の削除を制限します。新しく受信する録音では、停止後に分割音声を結合したconcat.wavを同じDriveフォルダへ追加保存します。分割版も残します。スマートフォンの音声キャッシュは、分割版の保存・時計への完了通知の登録、および結合版のDrive保存確認後に削除します。結合や送信が失敗した場合は、再試行のため端末内に保持します。録音一覧の表示や再試行に必要なメタデータはスマートフォン内に残ります。

時計からの削除ではGoogle Driveの録音は削除しません。Drive内の録音は利用者がGoogle Driveで削除できます。端末内のアプリデータはOSのアプリ管理機能で削除できますが、未送信の録音は失われる場合があります。

5. 開発者は録音データを収集・保管しません

開発者は、本アプリを通じて利用者の録音やGoogleユーザーデータを受け取らず、開発者側に保存しません。開発者が録音内容を閲覧・分析したり、販売・第三者提供したりすることもありません。広告、追跡、AI・機械学習への利用に限らず、開発者独自の目的でこれらのデータを利用しません。

アプリが行うデータ処理は、このポリシーに記載した利用者自身の録音・再生・保存・転送と、その管理に必要な範囲に限ります。Google APIから受け取る情報の利用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

6. 権限の管理

マイクなどの端末権限はOS設定から変更できます。Googleとの連携権限はGoogleアカウントの接続管理から取り消せます。取り消し後はDriveへの保存ができなくなりますが、既にDriveへ保存したファイルは自動削除されません。

7. このWebサイト

本サイトはGitHub Pagesで配信する静的な紹介サイトです。独自のアクセス解析、広告、問い合わせフォームは設置していません。ホスティング提供者のGitHubは、サイト配信や安全確保のためにアクセス情報を取り扱う場合があります。詳しくはGitHubのプライバシーステートメントをご覧ください。
